# combat
This project is a fantasy battle simulator, using objected oriented programming to create battles between three different character types: Warriors, Elves, and Wizards. Each character inherits a base class called Character, with each type implementing their own special attack behaviors. For example, two warriors belonging to the same allegiance and two elves belonging to the same family, would cause their attack damage to be zero. This program simulates a series of battles by selecting random attackers and defenders. After each battle, the remaining health of each character is displayed.
